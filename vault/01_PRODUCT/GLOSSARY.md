# Glossário geral (técnico)

Termos de **domínio** (Prompt, Avaliação, Marcador…) estão em [[DOMAIN_GLOSSARY]].

| Termo | Significado |
|---|---|
| **Claude Code** | CLI de codificação da Anthropic — primeiro CLI suportado |
| **Codex** | CLI de codificação da OpenAI — pós-MVP |
| **Hook `UserPromptSubmit`** | Gancho do Claude Code executado quando o usuário envia um prompt, **antes** de a LLM processá-lo; pode bloquear |
| **Plugin** | Pacote do Claude Code com hooks e comandos; o repositório guardIAn funciona como *marketplace* |
| **TypeSafe** | Empresa/API que fornece o JEV |
| **SSE** | Server-Sent Events — servidor empurra eventos para a UI |
| **Fail-open** | Em falha, deixar passar (em vez de bloquear) |
| **Fake** | Implementação falsa do avaliador usada em testes |
| **Tier** | Faixa de custo/capacidade de modelo (T1 barato, T2 intermediário, T3 avançado) |
